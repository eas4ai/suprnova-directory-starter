# Glossary

Status: Draft

| Term | Meaning in this project |
| --- | --- |
| Starter | MIT source application that a developer customizes into a directory. |
| Operator | Person or organization running a deployed directory. |
| Owner | Account that owns a listing. |
| Administrator | Account granted specific administrative permissions through Suprnova RBAC. |
| Listing | Directory record owned by an account; it is not a blog article. |
| Revision | A proposed or approved version of listing content. |
| Moderation | Review, approval, rejection or suspension of listing content. |
| Plan | Operator-configured publishing offer with provider-specific price mappings. |
| Entitlement | Application record of whether and for how long a listing qualifies for publication. |
| Provider | External payment service accessed through a Suprnova adapter. |
| Publication | Making eligible content visible on public directory surfaces. |
| Commitment | A bounded implementation outcome with requirements and checks; not a Git commit. |
| Falsifier | An observable result showing that a requirement is violated. |
| Mechanism | A declared command checking a requirement against identified inputs. |
